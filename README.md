# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/90f54607-36cb-4369-87fc-1005cc4140d0

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Optionally set `GEMINI_API_KEY` in `.env` to enable AI analysis and image/PDF extraction. The demo works without it.
3. Run the app:
   `npm run dev`

Open http://localhost:8080. See [PROJECT_NOTES.md](PROJECT_NOTES.md) for a short project overview.
